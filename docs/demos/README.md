# Demos (fake data, run on their own)

Self-contained pages that simulate the real thing with moving fake
data: open the file in any browser (or on the live site), no hardware,
no server. Use them to pitch a look, rehearse a lesson, or argue about
which wall display wins.

| Demo | What it fakes | Live |
| ---- | ------------- | ---- |
| [`mission-control.html`](mission-control.html) | Four takes on the classroom wall display (Flight Deck, Living Bin, Leaderboard, WORM//NET), six fake teams with drifting sensors and injected anomalies | [view](https://acklenx.github.io/raspberrypi/demos/mission-control.html) |

The real mission control lives in [`projects/mission-control`](../../projects/mission-control).
